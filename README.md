# guia-incapacidades

Página para que los colaboradores de Supertiendas Cañaveral envíen sus incapacidades y licencias desde el celular.

- `index.html`: la app (se publica con GitHub Pages).
- `Manual_colaborador_Envio_de_incapacidades.pdf`: manual del colaborador (botón "Ver manual (PDF)").

Modo prueba: agrega `?prueba=1` al final de la dirección.
